조합별 비용 비교

기본각인추가각인획득 점수총비용 · 만100점당 · 만

계산 기준

획득 점수 = (기본각인 4개 점수 + 추가각인 4개 점수 − 1,300) ÷ 2

100점당 비용 = 비서 8개 총비용 ÷ 획득 점수 × 100

공통 배율 = 목표 비용 ÷ 기준가에서 가장 비싼 조합의 100점당 비용

기준가는 비서 간 가격 비율을 정합니다. 기준가를 수정하면 모든 활성 비서의 자동 매입가가 함께 바뀝니다. 비활성 비서는 조합과 자동 매입가 계산에서 제외합니다. 소수점 점수는 유지하며, 아이템 자체 비용·수수료는 제외합니다. 자동 매입가는 게임머니 1 단위로 내림하여 목표를 넘지 않게 합니다.

GitHub Pages에 올리는 방법

‘HTML 코드 저장’으로 index.html을 내려받아 GitHub 저장소 최상위에 업로드하세요. 저장소 Settings → Pages → Deploy from a branch에서 main / (root)를 선택하고 저장하면 됩니다. 별도 설치나 빌드 없이 실행됩니다. 내려받은 코드는 기본 설정으로 시작하며 개인 설정은 각 브라우저에 저장됩니다.
